## ❓ 常见问题

### Q: 文档在哪里查看？
A: 所有文档都在 `docs/` 目录下，使用任何 Markdown 阅读器即可查看。

### Q: 如何搜索文档内容？
A: 
1. 使用编辑器的搜索功能 (Ctrl+F)
2. 使用 grep 命令: `grep -r "关键词" docs/`
3. 参考本索引的快速查找章节

### Q: 文档有错误怎么办？
A: 请提交 Issue 或直接修改后提交 Pull Request。

### Q: 如何生成 PDF？
A: 使用 Markdown 转 PDF 工具，如:
- Pandoc: `pandoc input.md -o output.pdf`
- VSCode 插件: Markdown PDF
- 在线工具: markdown-pdf.com
