## 📡 协议快速参考

### 帧格式
```
[5A A5][DIR][MOD][CMD][LEN][DATA...][CRC16]
```

### 模块ID
```
0x01 = 超声
0x02 = 射频
0x03 = 冲击波
0x04 = 热疗
```

### 命令ID
```
0x00 = 获取状态
0x01 = 设置工作状态
0x02 = 设置配置
```

### 方向
```
0x00 = 主机→设备
0x01 = 设备→主机
```

## 🚦 状态码速查

### 工作状态
```
0x00 = 停止
0x01 = 工作中
0x02 = 复位
```

### 连接状态
```
0x00 = 头部连接，脚踏关闭
0x01 = 头部连接，脚踏打开
0x10 = 头部断开，脚踏关闭
0x11 = 头部断开，脚踏打开
```

### 配置结果
```
0x00 = 成功
0x01 = 失败
0x02 = 超限
```

### 温度异常
```
0xFFFF = NTC开路 或 超限
0xEEFF = NTC短路
```

## 🎯 常用命令示例

### 获取超声状态
```
发送: 5A A5 00 01 00 01 00 [CRC]
接收: 5A A5 01 01 00 0E [14字节数据] [CRC]
```

### 启动射频治疗
```
发送: 5A A5 00 02 01 04
      01        // 启动
      3C 00     // 60秒
      0F        // 级别15
      [CRC]
```

### 设置超声配置
```
发送: 5A A5 00 01 02 0C
      B0 04     // 频率1200kHz
      DC 05     // 电压15V
      90 01     // 温度40℃
      E8 03     // 电流上限1000
      64 00     // 电流下限100
      64 00     // 剩余次数100
      [CRC]
```

## 📞 紧急处理

### 系统死机
```
1. 检查看门狗是否喂狗
2. 查看RTT日志
3. 检查CmBacktrace输出
4. 复位设备
```

### 通信异常
```
1. 检查波特率
2. 检查接线
3. 检查CRC计算
4. 查看发送/接收日志
```

### 治疗无法启动
```
1. 检查探头连接
2. 检查脚踏状态
3. 查看错误码
4. 检查剩余次数
5. 检查参数范围
```

### 温度异常
```
1. 检查NTC连接
2. 检查ADC采样
3. 检查温度限制
4. 立即停止输出
```
